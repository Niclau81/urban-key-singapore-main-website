# Real 360° Capture Operating Guide

## Scope

The Agent Portal's **360° capture quality check** accepts real room media for an agent-owned listing only. It is separate from UrbanKey's generated illustrative panorama previews. Uploading a file does **not** publish it, create a public tour, make a factual listing claim, or replace agent, owner, legal, or regulatory review.

## Intake prerequisites

Before upload, the agent must confirm that the listing owner or authorised representative has permitted the capture and that required capture consent has been obtained. The capture must be a JPG or WebP equirectangular source at least 3000 × 1500 pixels, close to a 2:1 aspect ratio, and intended to cover 360° horizontally and 180° vertically. The current workspace accepts files below 20 MB.

## Private quality workflow

| Stage | Required control | Result |
|---|---|---|
| **Private intake** | Owner authorisation and capture consent are affirmed. | The media is stored privately with listing and uploader ownership metadata. |
| **Technical baseline** | Resolution, near-2:1 aspect ratio, and declared 360° × 180° coverage are checked. | The capture is marked technically ready or retained for correction. |
| **Privacy review** | Agent reviews face, family-photo, document, letter, card, name, access-code, screen, and visible personal-information risks. | A reviewer records cleared, redaction-required, or rejected status with notes. |
| **Independent approval** | A separate administrator approves a complete, reviewed capture. | Only then may a future publication workflow make it available as a verified 360° tour. |

## Current limitations and publication boundary

The current quality-check screen records privacy and technical gates but does not yet perform automatic pixel blurring, publish a real capture to the public viewer, or submit anything to an external platform. AI-assisted detection should be integrated as **redaction proposals** before manual confirmation; it must not be treated as a substitute for a human privacy review. A future publication procedure should create the verified panorama route only from independently approved captures, preserve the audit record, and provide an unpublish action.

## Generated media boundary

Marina Cove, The Interlace, and Queenstown use only **original illustrative generated photo and panorama previews**. Their persistent disclosure must remain visible, and they must never be recast as a real unit survey or verified 360° capture.
